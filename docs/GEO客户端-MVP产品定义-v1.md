# GEO 客户端（Mac/Windows）MVP 产品定义 v1.0

> 面向国内中小企业的生成式引擎优化（Generative Engine Optimization）桌面工具
> 文档状态：MVP 立项稿 · 编制日期 2026-09-16 · 负责人：产品

---

## 0. 一页结论（TL;DR）

**产品一句话**：让中小企业在自己电脑上，用 15 分钟看清"豆包 / DeepSeek / Kimi / 元宝 里搜我的品类，有没有我、排第几、说错了什么"，并直接拿到可执行、可复测的 GEO 改造清单。

**MVP 只做一条闭环价值链**（缺任一环就不成立）：

```
建题(Prompt 题库) → 采集(多引擎真实回答) → 解析(提及/位次/情感/引用/事实)
   → 诊断(可见度评分 + 竞品对标) → 行动(GEO 处方 + 内容生成) → 复测(归因提升)
```

**为什么是桌面客户端**（而非 SaaS）：
1. 采集合规与成本可控——用户自带引擎账号 / API Key，请求从本地发起，平台不承担大规模集中抓取的封号与法务风险；
2. 数据主权——品牌档案、竞品清单、原始回答快照全部留在本地（对标国内已出现的"本地 GEO 智能体"卖点）；
3. 长任务本地跑——60~100 prompts × 7 引擎 × 多轮 = 上千次请求，需要本地队列、断点续跑、夜间定时；
4. 无官方 API 的引擎（元宝、豆包网页版、百度 AI 搜索）只能靠本地登录态浏览器自动化，桌面端天然可行；
5. 渠道变现——客户端可直接做 OEM / 买断授权给 GEO 代运营与营销服务商（国内已验证的付费意愿）。

**定价锚点**：体验版 ¥0 / 专业版 ¥399 月（¥2,999 年）/ 服务商版 ¥1,299 月 / 渠道买断 ¥19,800。显著低于国内代运营 ¥2,800~5,500/月的行情，主打"自己看得见、可验证"。

**12 周交付**：W1–2 引擎通道技术验证（go/no-go）→ W3–8 基座 + 采集 + 解析 → W8–10 诊断 + 行动 + 报告 → W10–12 封闭测试与发布。

**最关键的差异化**：海外工具被用户吐槽"you are buying signal, not strategy"（只给数据不给动作）。MVP 把 **GEO 行动中心（M6）** 做成一等公民——每条诊断都必须挂一条可执行处方，并能在下一轮复测中被归因验证。

## 1. 市场与竞品洞察（决策依据）

### 1.1 海外格局：品类已成型，价格与功能分层清晰

- 品类热度：`generative engine optimization` 在美国月搜索量约 **22,200 次**（2026 年，IndustryLens 追踪），已从概念变成有明确工具生态的品类。
- 零点击压力：2026 年前 4 个月 **68.01% 的 Google 搜索没有产生点击**（Otterly 统计），信息型内容首当其冲——这是企业愿意为"AI 答案里的可见度"付费的根本原因。
- 采用意愿：**94% 的企业高管预计 2026 年会增加 AEO/GEO 预算**（Conductor × Sapio，400+ 决策者调研）。
- 资本信号：Adobe 以 **19 亿美元** 收购 Semrush，Semrush AI Toolkit 取消免费档、入门价升至 **$165.17/月**——大厂入场，独立工具向"执行侧"迁移。

**海外主流工具价格与配额（2026 年公开定价）**

| 工具 | 入门价 | 入门档配额 | 每千 prompt 估算成本 | 定位 |
|---|---|---|---|---|
| Rankscale | ~$20/月 | ~1,000 prompts | ~$20 | 独立顾问验证性使用 |
| Otterly.AI | $29/月 | ~150 searches | ~$190 | 轻量月度巡检 |
| Peec AI | ~$49/月（年付 Brand Starter 降至 $80/月档） | ~300 prompts | ~$165 | 侧重 Google AI Overviews |
| AthenaHQ | 免费 Essential 档 | 300 credits/月 | — | 面向 SMB / 个人，ACE 预测式引用建模 |
| Scrunch AI | ~$199/月 | ~2,500 prompts | ~$80 | 内部营销团队向上汇报 |
| Profound | $399/月 | ~5,000 prompts | ~$80 | 企业级常态化 GEO，FactCheck / Citation Decay |
| Semrush AI Toolkit | $165.17/月 | — | — | SEO 套件附加模块 |
| Brandlight | 最高 $25,000/月 | — | — | 企业级全托管 |

> 结论 1：**入门价格带 $20~$50 是"验证期"，$100~$400 才是留存区**。国内中小企业可承受区间大致对应 ¥200~¥600/月，与代运营 ¥2,800+/月 之间存在明显空白。
> 结论 2：成本差异主要来自 **prompt 配额、刷新频率、引擎覆盖、归因深度** 四个变量——这正是我们做套餐分层的抓手。

**功能演进方向（决定 MVP 该抄什么、该超什么）**
- 从"监测"走向"纠正与预测"：Profound 上线 **FactCheck**（监测并纠正 AI 回答中的事实错误）与 **Citation Decay**（周环比引用留存）；AthenaHQ 上线 **ACE**（发布前预测内容被引用概率）。
- 从"品牌"走向"信源指数"：Ahrefs Brand Radar 用双索引方法追踪 4.66 亿次月度提及。
- 标配引擎：ChatGPT / Gemini / Perplexity / Google AI Overviews 是"桌面赌注"，Copilot、Claude 通常放在更高档套餐。

### 1.2 海外用户实测数据：直接影响我们的指标设计

Otterly 追踪 **520 个 prompts、7 个引擎、40~91 天、252,407 条 AI 回答**，得出四条对产品设计有硬约束的结论：

1. **品牌提及比引用来源稳定**：30 天窗口内只出现一天的品牌占比仅 **12%~19%**；而引用来源的"一次性出现"比例高达 **26%~67%**（Google AI Mode 约 2/3）。
2. **样本量决定可信度**：从 10 条 prompt 增加到 100 条，Brand Coverage 的波动幅度下降约 **73%**。
3. **引用来源日间留存差异极大**：ChatGPT 与 Google AI Mode 仅保留前一日约 **25%** 的来源，Perplexity 保留约 **75%**。
4. **长尾极端**：45,919 个被引 URL 中 **48% 只被引用过一次**，Top 1% 贡献了 **44%** 的引用；每个 prompt 月均涉及 ~95 个来源，但只涉及 ~10 个品牌。

> 产品决策（必须写进 PRD）：
> - **Brand Coverage 作为头号 KPI，引用来源作为诊断层**；UI 必须显式标注"引用层日间波动属正常现象"，避免用户误读为"效果掉了"。
> - **默认 prompt 样本量 ≥ 60 条**，低于阈值时在报告上打"样本不足"水印，绝不给出看似精确的分数。
> - 关键 prompt 支持 **重复采样（2~3 次）** 并展示波动区间，而不是只跑一次就给结论。

其他可直接复用的行业事实：ChatGPT 在 2026 年 8 月把 Reddit 引用削减 ≥73%，缺口由权威参考源与官方页面填补；与 OpenAI 签约的新闻出版商在 ChatGPT 上多获得 **+48%** 的引用。→ 说明"信源结构"是可运营变量，行动中心要给出**信源类型层面的建议**（官方页 / 百科 / 权威媒体 / UGC）。

### 1.3 海外 UX 的可复用设计与被抱怨的点

**值得照搬的 UX 模式**
- 5 分钟出价值的 Onboarding：输入域名 → 自动生成 prompt 集 → 选引擎与频率 → 立刻产出基线报告。
- 竞品同框对标（Share of Voice）：Standard 档跟 5 个竞品、Pro 档跟 50 个。
- 四维指标语言统一：Visibility（可见度）/ Position（位次）/ Sentiment（情感）/ Share of Voice（声量）。
- 报告可分享、可白标（代理商刚需）。

**被抱怨的点 = 我们的机会**
| 用户抱怨 | MVP 对策 |
|---|---|
| "只告诉我哪里错了，不告诉我怎么修" | M6 行动中心：每条诊断挂处方 + 一键生成内容 + 执行状态跟踪 |
| 低价档"手工活多，买的是信号不是策略" | 桌面端把采集、解析、报告全自动化，本地跑重任务不心疼配额 |
| 数据抖动、10 条 prompt 就出分数，不敢信 | 样本量阈值 + 置信区间 + 原始回答快照证据链 |
| 看不见成本，怕超支 | 本地成本看板：每轮采集预估/实际 token 与查询次数，硬配额上限 |

### 1.4 国内格局：服务重、工具轻，信任是最大缺口

- 市场规模（多口径）：艾瑞测算 **2025 年中国 GEO 服务市场 87.6 亿元**；信通院口径 **2026 年突破 286 亿元、同比 +125%、渗透率由 38% 升至 71%**；爱分析预测 **2026–2030 年 CAGR > 130%，2030 年约 1,376 亿元**。
- 流量入口已成事实：QuestMobile 2026 年 Q1，**豆包 MAU 3.45 亿、千问 1.66 亿、DeepSeek 1.27 亿**，AI 原生 App 月活合计 **4.4 亿**。企业客户的问题不再是"要不要看 AI 搜索"，而是"我在里面长什么样"。
- 供给侧结构：**以全链路代运营/服务为主，工具化产品稀缺**。行情价：垂直行业代运营 **¥2,800~5,500/月**、人工代运营 **季度 ¥8,000~18,000**、成长型品牌 **¥8,000~15,000/月**、年度套餐 **¥139,800/年**、深度托管 **¥100,000+/年**。
- 已有工具/竞品：
  - **SheepGeo**：SHEEP 五维评分（语义覆盖、人类可信度、证据结构化、生态集成、性能监测），检测网站在豆包/千问/智谱等的可引用性；
  - **GEOBase（AIbase）**：6 大能力（AI 对话问题挖掘、GEO 排名查询、品牌得分检测、推广链接检测、排名监测、品牌全景分析）；
  - **GEO 探针**：多平台排名与品牌提及监测、周期报告、多竞品；
  - **灰豚 GEO**：OEM 贴牌 / 源码私有化部署，**¥15,800** 级别买断（面向站长、跨境、海外营销机构、SaaS）；
  - **简曜 GenAura（边界智能）**：2026 年 7 月上线**本地版客户端**，从云端工具进化为"本地 GEO 智能体"，主打 SEO+GEO 双引擎与"品牌诊断→真实监测→全面洞察→智能建议→效果跟踪"六步闭环，卖点直指"数据进 AI 是否安全"。← **最直接对标，必须差异化**
- 行业信任危机（我们的定位机会）：市场充斥"AI 排名前三""7 天霸屏""万词覆盖"话术，淘宝出现 ¥1 代运营；2026 年 8 月五大 AI 引擎集中算法更新后大量代运营"翻车"。中小企业最大的痛点不是没有服务商，而是**无法验证服务商说的话**。

> 结论：国内空白点是"**中小企业买得起、结论可自证、动作可落地**"的工具。MVP 的产品人格应是"**可验证的 AI 可见度体检仪 + 处方笺**"，而不是又一个"排名保证"的黑盒。

### 1.5 桌面端形态的风险与缓解（必须提前认账）

| 风险 | 缓解 |
|---|---|
| 引擎频繁改版，客户端适配滞后 | 引擎适配器插件化 + 云端规则热更新（不发版即可修选择器/解析规则），承诺 48~72h 适配 SLA |
| 无法沉淀跨客户行业基准（SaaS 的数据飞轮优势） | 可选匿名基准池（用户显式授权后共享脱敏行业均值），默认关闭 |
| 安装门槛、签名/公证、盗版与授权 | 代码签名 + 公证，设备绑定 License，离线可用但采集需联网 |
| 用户自带账号被封风险 | 频控 + 随机间隔 + 优先官方 API + 明示风险与降级策略，不绕过验证码 |

## 2. 目标客户与核心场景

### 2.1 ICP（理想客户画像）

**主要客户（MVP 必须服务好）**
- 年营收 500 万~5 亿元、有官网/小程序/电商店铺、市场人员 1~3 人的中小企业；
- 优先行业：**B2B 制造与工业品、企业服务/SaaS、本地生活与专业服务（法律/医疗民营/装修/教培）、跨境电商、招商加盟**——这些行业决策链长、依赖"问 AI 做选型"，且现有内容资产薄，改善空间大；
- 决策人：老板/市场负责人本人；预算权限：¥3,000~¥30,000/年可自主决定。

**次要客户（高 ARPU、口碑放大器）**
- GEO 代运营公司、数字营销 agency、SEO 服务商：需要多项目管理、白标报告、向客户自证效果。MVP 用"服务商版 + 买断授权"覆盖。

**MVP 明确不服务**
- 大型集团私有化部署与定制开发；
- 需要复杂权限/审批流/多部门协作的组织；
- 只买"保证排名"结果的投机型客户（产品价值观上不做承诺式话术）。

### 2.2 五个核心场景（Jobs to be Done）

1. **体检**："老板问豆包里搜我们品类有没有我们" → 15 分钟出基线体检报告（含原始回答快照）。
2. **验证**："代运营说做到前三了，我怎么核实？" → 可复现证据链：prompt + 引擎 + 时间戳 + 完整回答 + 截图。
3. **落地**："我知道没曝光了，然后呢？" → Top 10 行动处方 + 一键生成 GEO 友好内容 + 官网结构化改造清单。
4. **汇报**："每周要给老板/客户交报告" → 自动周报（PDF/Excel/PNG），支持白标。
5. **预警**："引擎又改版了，我的提及率掉了" → 本地告警 + 归因（哪个引擎、哪类意图、哪些信源掉了）。

## 3. MVP 核心功能包（产品主体）

### 3.1 范围原则

1. **闭环优先**：任何不能影响"下一轮复测得分"的功能，一律进 P1/P2。
2. **证据优先**：每个分数都能下钻到原始回答与截图，拒绝黑盒评分。
3. **成本透明**：用户随时知道这一轮采集花了多少（token / 查询次数 / 预估人民币）。
4. **可交付物导向**：输出必须是客户能直接用的东西（报告、清单、可发布内容），而不是仪表盘截图。
5. **合规内建**：不承诺排名、不刷量、不伪造信源、不绕过验证码与登录风控。

### 3.2 模块总览

| # | 模块 | 优先级 | 一句话价值 | 对标 |
|---|---|---|---|---|
| M1 | 项目与品牌档案 | P0 | 3 分钟建项目，沉淀"事实真值" | Peec / Otterly onboarding |
| M2 | Prompt 智能题库 | P0 | 60~100 条真实用户问法，保证统计可信 | Otterly / Scrunch |
| M3 | 多引擎采集引擎 | P0 | 国内 7 引擎真实回答 + 原始证据留存 | Otterly（引擎覆盖）+ 国内空白 |
| M4 | 解析与事实核查 | P0 | 提及/位次/情感/引用/错误一次算清 | Profound FactCheck |
| M5 | 诊断与竞品对标 | P0 | 一屏看懂"我在哪、差多少、哪最烂" | AthenaHQ / Scrunch |
| M6 | **GEO 行动中心** | P0 | 从数据到处方到内容，闭环归因 | **差异化核心**（海外普遍缺失） |
| M7 | 报告与分享 | P0 | 老板版/执行版/白标版一键出 | 代理商刚需 |
| M8 | 客户端基座 | P0 | 本地安全、任务调度、成本看板、双端签名 | 简曜本地版 / 灰豚私有化 |
| M9 | 服务商多项目与白标 | P1 | 一账号管 20+ 客户项目 | Peec Agency 档 |
| M10 | 可选云同步与行业基准 | P1 | 数据飞轮、团队协作、移动端看数 | Ahrefs Brand Radar |

### 3.3 M1 · 项目与品牌档案（P0）

**功能点**
- 新建项目向导（5 步）：品牌名与别名/常见错写 → 官网与核心页面 → 产品线与服务范围 → 目标地域与语言 → 竞品 3~5 家。
- **自动建档**：输入官网域名，自动抓取首页/About/产品页/FAQ/联系方式，用 LLM 生成结构化"品牌实体卡"：标准名称、别名、成立年份、资质认证、核心产品与参数、价格区间、服务地域、代表案例、差异化卖点、官方口径话术。
- **实体卡即真值源（Ground Truth）**：M4 的事实核查、M6 的内容生成全部以它为准，人工可逐字段修订并留痕（修订记录用于后续"AI 说错了"的举证）。
- 项目资产登记：自有页面清单、第三方信源清单（百科词条、知乎、小红书、百家号、行业媒体、电商详情页）、社媒账号。
- 多项目管理、标签、归档、导入导出（JSON/CSV）。

**验收标准**
- 全新用户 ≤3 分钟完成一个项目创建，实体卡自动生成字段完整率 ≥80%；
- 实体卡每个字段可编辑、可标注"官方口径/待确认"，修改后触发下一轮核查基准更新。

**为什么这样设计**：国内中小企业最缺的不是监测，而是"AI 眼里的我"与"真实的我"之间的差异清单。实体卡把这件事变成结构化资产，是行动中心能自动开处方的前提。

### 3.4 M2 · Prompt 智能题库（P0）

**功能点**
- **意图分层生成器**（默认 7 类，行业模板可扩展）：
  1. 品类认知（"XX 是什么/有哪些"）
  2. 选购推荐（"XX 哪家强/推荐几个"）
  3. 品牌对比（"我们 vs 竞品 A/B"）
  4. 价格与方案（"XX 多少钱/怎么收费"）
  5. 本地与服务（"XX 附近/上门服务"）
  6. 售后与口碑（"XX 靠谱吗/投诉/避坑"）
  7. 专业长尾（参数、认证、场景化技术问法）
- **中文口语化改写**：把书面词转成真实用户问法（"哪个好""靠谱吗""多少钱""是不是智商税"），支持行业黑话与地域变体。
- **竞品同框 prompt**：强制生成把品牌与竞品放进同一问题的 prompt，才能算出可信的 Share of Voice。
- **样本量控制**：默认建议 60~100 条；低于 30 条时报告标注"样本不足，仅供方向性参考"，并显示当前样本的波动区间（依据：10→100 prompts 可使 Brand Coverage 波动下降约 73%）。
- Prompt 管理：手动增删改、相似度去重合并、权重（核心词加权）、分组、CSV 导入导出、版本管理（每轮复测记录使用的 prompt 集版本，保证可比性）。
- 从真实流量反向挖题（P1）：接入用户自有的站内搜索词/客服问答/评论区，生成更贴近真实需求的 prompt。

**验收标准**
- 一键生成 ≥60 条、覆盖 7 类意图、去重后无近义重复率 >15%；
- 同一项目二次采集默认沿用同一 prompt 集版本，得分可直接环比。

### 3.5 M3 · 多引擎采集引擎（P0，技术核心）

**引擎矩阵（MVP 范围）**

| 优先级 | 引擎 | 建议通道 | 备注 |
|---|---|---|---|
| P0 | 豆包（字节） | 官方 API（火山方舟 / 豆包搜索开放服务，2026-07 起面向 Agent 提供 markdown+结构化返回）+ 网页版浏览器自动化兜底 | 国内 MAU 第一入口（3.45 亿） |
| P0 | DeepSeek | 官方 API（OpenAI 兼容，成本极低：V4 Flash 输入约 1 元/百万 token，缓存命中约 0.02 元） | 联网检索能力需在 W1 spike 验证，必要时走网页版 |
| P0 | Kimi（Moonshot） | 官方 API 内置 `$web_search`（Basic/Pro）+ 网页抓取 | 官方文档提示联网搜索能力在升级中，需准备降级方案 |
| P0 | 通义/千问（阿里） | 百炼 API `enable_search` + `search_strategy=agent_max` | 千问 App MAU 1.66 亿 |
| P0 | 腾讯元宝 | 本地浏览器自动化（无公开对话 API） | 需用户扫码登录，会话持久化 |
| P0 | 百度 AI 搜索 / 文心 | 千帆 API（搜索增强）+ 网页自动化兜底 | 传统搜索入口迁移的主战场 |
| P0 | 秘塔 Metaso | 官方搜索 API，约 **0.03 元/次查询**，注册送 5,000 点额度 | 成本最低的"专业搜索型"引擎，适合高频复测 |
| P1 | 智谱清言、讯飞星火、夸克、天工 | API / 网页自动化 | 按客户行业需求排期 |
| P1/P2 | ChatGPT、Perplexity、Gemini、Google AI Overviews、Claude、Copilot | 官方 API（需用户自备海外 Key 与网络） | 服务跨境电商客户；默认关闭，涉及数据出境需明示 |

**三种采集通道（适配器架构）**
- **A. 官方 API（BYOK）**：用户填自己的 Key，本地直连；成本最低、最稳定、最合规。内置各平台免费额度提示（火山每日 200 万 tokens、阿里云百炼 100 万 tokens、百度千帆每模型 100 万 tokens/3 个月、腾讯混元 100 万 tokens/年）。
- **B. 本地浏览器自动化**：内置受控 Chromium（Playwright/CDP），每引擎独立 profile，复用用户登录态；支持人工接管（遇到验证码/风控时弹窗交给用户完成，不自动绕过）。
- **C. 内置网关（可选）**：平台侧提供已签约的模型/搜索网关，按量计费，降低小白用户配置门槛。

**任务调度与稳定性**
- 队列化执行：并发上限、请求间隔随机化、单引擎频控、夜间定时任务、断点续跑、失败自动重试与通道降级（API 失败 → 浏览器）。
- **原始证据留存**（产品护城河）：每条记录保存 prompt 原文、引擎与模型版本、完整回答文本、引用链接列表、页面截图、时间戳、通道类型、耗时与成本。所有分数可回溯到原始快照。
- **重复采样**：关键 prompt 可设 1/2/3 次重复，输出提及率的区间而非单点值。
- 代理与网络设置：支持 HTTP/SOCKS 代理、按引擎分配代理、失败自动切换。
- **成本看板**：每项目每轮的预估消耗（查询次数 × 单价 + token 估算）与硬配额上限，超额自动暂停并提示。

**验收标准**
- 7 引擎 × 60 prompts 一轮采集 ≤90 分钟完成，整体成功率 ≥90%，失败条目显示原因并可单独重跑；
- 单条记录可一键打开原始回答与截图；
- 成本误差 ≤15%（预估 vs 实际）。

### 3.6 M4 · 回答解析与事实核查（P0）

**功能点**
- **结构化抽取**（LLM + 规则双通道）：
  - 品牌提及：本品牌 / 竞品 / 其他品牌；提及次数与上下文片段；
  - **推荐位次**：是否进入推荐清单、第几位、是否被写入对比表格、是否被列为"首选/性价比之选"；
  - **情感倾向**：正面 / 中性 / 负面 + 关键评价短语抽取；
  - **引用来源**：URL、域名、来源类型自动归类（自有官网 / 百科 / 新闻媒体 / 知乎问答 / 小红书等 UGC / 电商页 / 官方文档 / 论坛）；
  - **回答形态**：是否给出结论、是否有表格、是否反问、是否拒答。
- **事实核查（对标 Profound FactCheck）**：回答内容与 M1 品牌实体卡逐字段比对，输出三类问题——**说错了**（价格、成立年份、资质、地址、服务范围）、**说旧了**（过时案例/停产型号）、**漏说了**（关键卖点未覆盖）。
- **风险标记**：涉医疗/金融等强监管表述、绝对化用语（广告法风险）、疑似幻觉内容、负面舆情关键词。
- **抽取质量保障**：双模型交叉校验 + 置信度打分 + 低置信度样本人工复核队列；用户可一键纠正，纠正样本回流为 few-shot/规则，持续提升准确率。

**验收标准**
- 品牌提及识别准确率 ≥95%、推荐位次 ≥90%、情感 ≥85%（基于 500 条人工标注集）；
- 事实核查每条问题都能定位到"回答原文片段 vs 实体卡字段"的对照，误报可一键标记并计入质量统计。

### 3.7 M5 · 可见度诊断与竞品对标（P0）

**指标体系（锁定口径，写进帮助文档）**
- **头号 KPI：Brand Coverage（品牌覆盖率）** = 被提及的 prompt 数 / 有效采集 prompt 数。理由：品牌提及显著比引用来源稳定（一次性出现比例 12%~19% vs 26%~67%）。
- 二级指标：Share of Voice（同框 prompt 中本品牌 vs 竞品提及份额）、推荐位次分布（Top1/Top3/仅提及）、情感占比、事实准确率、引用来源结构占比。
- 诊断层指标（明确标注"波动正常，用于归因"）：被引域名 Top20、来源类型分布、来源留存率（对标 Citation Decay：本周被引来源在上周的占比）。

**视图**
1. **体检总分（0–100）**：按 可见度 / 推荐力 / 口碑情感 / 事实准确 / 信源健康 五维加权，每维可下钻到具体 prompt 与原始回答。**总分旁必须显示样本量与置信区间**。
2. **竞品对标矩阵**：行=品牌，列=指标；支持按引擎、按意图类切片。
3. **意图漏斗**：认知层（品类问题）→ 推荐层（选购问题）→ 决策层（对比/价格）逐层提及率。国内中小企业最常见病症是"认知层有、推荐层无"，漏斗视图能一眼定位。
4. **引擎差异视图**：哪个引擎最认可你、哪个最容易说错你（按事实错误率排序）。
5. **趋势与波动**：周/月环比折线 + 显著变化标注（超过阈值自动打点说明可能原因，如引擎算法更新）。
6. **告警**：Brand Coverage 环比下降超阈值、出现负面评价或事实错误、竞品超越 → 本地系统通知 + 应用内红点。

**验收标准**：新用户打开报告 30 秒内能回答"我在哪、和竞品差多少、哪个引擎最差、下一步做什么"。

### 3.8 M6 · GEO 行动中心（P0，差异化核心）

> 这是与海外工具拉开差距的模块。海外评测的原话是："These tools show where AI engines get your company wrong; **they do not close the gap**."

**功能点**
- **自动处方**：基于诊断结果生成 Top 10 行动项，每项包含：影响的 prompt/引擎范围、预期收益（高/中/低 + 依据）、实施难度、负责人建议、可交付物模板。
- **四类处方库**
  1. **官网与内容结构化**：可被引用的定义句与数据表、FAQ 区块与 Schema 标记、清晰的实体信息（公司名/地址/资质/成立时间统一口径）、页面精简与要点前置、更新时间与作者署名、`llms.txt`、`robots.txt` 对 AI 爬虫（GPTBot/ClaudeBot/Bytespider 等）的放行策略。
  2. **信源布局**：缺失的高价值引用域名清单（按行业引用习惯给出优先级：官方页 > 权威媒体 > 百科 > 垂直社区 > UGC），每个域名给出"该发什么内容 + 模板 + 合规提示"。依据：AI 引用的内容中约一半是企业自撰页面，且 2026 年 8 月后 ChatGPT 大幅削减论坛引用、转向权威源与官方页。
  3. **事实纠错**：全网错误信息清单（哪个引擎、哪条回答、错在哪个字段）+ 更正路径（官网 About、百科词条、第三方页面、客服话术、招聘/黄页信息）。
  4. **内容生产（与仓库现有 `gdk_auto_article` 自动成文能力打通）**：一键生成 GEO 友好内容——问答体文章、品类对比表、参数规格卡、案例卡、FAQ 页、行业术语解释页；支持批量、行业模板、中文口语化风格、导出 Markdown / DOCX / HTML，并可生成本地站点可上传的静态文件包。
- **执行跟踪与闭环归因**：行动项状态（待办/进行中/已完成）+ 完成时间，自动关联到下一轮复测的得分变化，输出"做完这 3 项 → 豆包提及率 +18%、事实错误 -5 条"的归因卡片。**这是续费理由，也是对抗代运营黑盒的武器**。
- **合规红线（产品级约束）**：不生成虚假案例/资质；不用绝对化用语；不做批量刷量与伪造信源；生成内容默认进入"待人工审核"状态；报告与营销物料禁用"保证排名/霸屏"表述。

**验收标准**
- 每个项目自动产出 ≥10 条可执行动作，其中 ≥3 条可在 1 小时内完成（如补 FAQ、加 llms.txt、统一实体口径）；
- 已完成动作与复测得分变化可在同一视图关联展示；
- 内容生成产物可直接导出使用，格式正确率 100%。

### 3.9 M7 · 报告与分享（P0）

- 一键生成三种版本：**老板版**（1 页结论 + 3 个数字 + 下一步）、**执行版**（明细表 + prompt 级证据）、**客户白标版**（自定义 Logo、公司名、联系方式、指标口径说明）。
- 格式：PDF（中/英）、Excel 明细、PNG 看板图、HTML（本地文件或可选云链接）。
- **证据附录**：原始回答快照 + 截图 + 时间戳 + 引擎版本，可独立导出，用于向老板/客户自证。
- 定时自动生成（周报/月报）+ 输出到本地文件夹 / 邮件 / Webhook。
- 报告口径说明页：固定写明样本量、采集时间、引擎列表、指标定义与"AI 回答存在随机性"的免责声明——**这是建立行业信任的关键设计**。

### 3.10 M8 · 客户端基座（P0）

- **技术栈建议**：Tauri 2（Rust 内核 + 系统 WebView，安装包 <20MB，内存占用优于 Electron）；若浏览器自动化依赖复杂，可评估 Electron + 内置 Chromium。本地存储 SQLite（SQLCipher 加密）/ DuckDB（分析查询）。
- **安装与分发**：macOS 代码签名 + 公证（含 Apple Silicon/Intel 双架构），Windows 代码签名（规避 SmartScreen 警告）；自动更新（增量）；离线可用（除采集与模型调用外）。
- **凭据与数据安全**：引擎账号与 API Key 存系统钥匙串 / Windows 凭据管理器；本地数据库加密；一键清除全部数据；项目导出/迁移。
- **任务与可观测**：任务中心（进行中/排队/失败重试）、运行日志、采集成功率与成本统计、一键打包诊断日志（需用户同意后上报）。
- **授权**：设备绑定 License + 轻量云端校验；支持试用、离线宽限期、渠道买断授权码。
- **设置**：代理、并发、频控、模型选择（BYOK / 内置网关 / 本地模型可选）、语言、通知。

**验收标准**：从下载到看到第一份基线报告 ≤15 分钟；双端安装无安全警告；崩溃率 <1%；断网时已采集数据仍可完整查看与导出。

### 3.11 M9 / M10（P1，MVP 后第一优先）

- **M9 服务商版**：多项目分组与客户维度看板、白标模板库、批量采集计划、团队 2~5 席位、对账单（按客户核算成本，方便代运营加价转售）。
- **M10 可选云同步**：加密备份、跨设备同步、移动端看数（只读）、**匿名行业基准池**（用户显式授权后贡献脱敏指标，换取"我在同行业处于什么分位"）——这是桌面端补齐 SaaS 数据飞轮的唯一路径。

### 3.12 MVP 明确不做（Out of Scope）

- ❌ 自动向第三方平台发布内容 / 自动铺量（封号与合规风险，且违反产品价值观）；
- ❌ 任何"保证排名 / 霸屏 / 万词覆盖"类功能与话术；
- ❌ 刷量、伪造信源、模拟用户提问投票；
- ❌ 团队协作权限体系、审批流、多人实时编辑；
- ❌ 移动端 App、浏览器插件；
- ❌ 传统 SEO 工具链（外链、关键词排名、站内技术审计）——只在行动中心给出必要的技术建议；
- ❌ 私有化服务器部署（本地客户端已覆盖该诉求）；
- ❌ 跨客户行业基准大盘（依赖 M10 的授权机制）。

## 4. 指标体系与统计严谨性（不可妥协的产品纪律）

AI 回答具有随机性，国内已出现大量"数据不可信"的吐槽。MVP 必须把统计纪律做成产品特性：

| 纪律 | 实现方式 |
|---|---|
| 样本量下限 | 默认 ≥60 prompts；<30 时报告打"样本不足"标识，不显示精确分数 |
| 波动可见 | 关键 prompt 重复采样，展示区间（如 Brand Coverage 42%±6%）而非单点 |
| 口径版本化 | prompt 集、引擎列表、模型版本、采集时间随每轮快照存档，保证环比可比 |
| 指标分层 | Brand Coverage = 头号 KPI；引用来源 = 诊断层，UI 显式标注"日间波动属正常" |
| 证据可回溯 | 任何分数点击即可看到原始回答、截图、时间戳 |
| 不做绝对化表述 | 全产品文案禁用"排名第一/保证/霸屏"，改用"可见度/覆盖率/提及份额" |

**北极星指标（产品内部）**：周活跃项目中，**完成一轮复测且执行 ≥1 个行动项** 的比例——只有这个行为能证明"数据→动作→效果"闭环成立。

## 5. 商业模式与定价

### 5.1 单位成本测算（按 1 个项目 / 月，60 prompts × 7 引擎 × 4 轮 ≈ 1,680 次查询）

| 成本项 | 估算 | 说明 |
|---|---|---|
| 引擎查询 | ¥50~150 | 秘塔约 0.03 元/次；其余按 token 计（DeepSeek V4 Flash 输入约 1 元/百万 token，缓存命中约 0.02 元）；各平台普遍提供大额免费额度 |
| LLM 解析与生成 | ¥30~120 | 结构化抽取 + 事实核查 + 内容生成，可用低价模型 + 缓存优化 |
| 浏览器自动化（无 API 引擎） | 用户侧成本 | 用户自有账号与设备算力，平台边际成本≈0 |
| **合计边际成本** | **¥100~300 / 项目 / 月** | BYOK 模式下平台成本进一步趋近于 0 |

### 5.2 套餐建议

| 版本 | 定价 | 配额与能力 | 目标 |
|---|---|---|---|
| 体验版 | ¥0 | 1 项目 / 20 prompts / 3 引擎 / 单次采集 / 报告带水印 / 不含行动中心导出 | 获客、验证价值 |
| 专业版 | **¥399/月 或 ¥2,999/年** | 3 项目 / 100 prompts / 7 引擎 / 周更 / 行动中心 + 内容生成 / 全格式报告 | 中小企业主力 |
| 服务商版 | **¥1,299/月** | 20 项目 / 白标报告 / 更高并发 / 优先引擎适配 / 5 席位 | 代运营与 agency |
| 渠道买断 | **¥19,800 一次性 + ¥3,980/年维护** | 本地私有授权、可贴牌 | 对标灰豚 GEO 源码买断（¥15,800 级）市场 |

**定价逻辑**：锚定在国内代运营 ¥2,800~5,500/月 之下、海外同类 $29~$199/月 的合理换算区间内；同时用"证据可验证"替代"效果承诺"，避开低价刷量市场的恶性竞争。

### 5.3 增长路径

1. **免费体检钩子**：官网/公众号提供"输入域名 → 领取一份 AI 可见度体检报告（体验版生成）"，用报告本身的震撼度（"豆包说错了我 3 个事实"）驱动转化；

## 附录 C · 体检评分公式草案（五维加权，总分 100）

```
总分 = 0.35×可见度 + 0.25×推荐力 + 0.15×口碑情感 + 0.15×事实准确 + 0.10×信源健康

可见度   = Brand Coverage（被提及 prompt 占比）×100
推荐力   = (Top1 权重1.0 + Top3 权重0.7 + 仅提及权重0.3) 的加权占比 ×100
口碑情感 = 正面提及占比 ×100 − 负面提及占比 ×50（下限 0）
事实准确 = 1 − (事实错误条数 / 涉及本品牌的回答条数)，×100
信源健康 = (自有页 + 权威源引用占比) ×60 + 引用域名去重数归一化 ×40
```
> 所有分项在 UI 中必须可下钻到 prompt 与原始回答；样本不足时总分置灰并提示"数据不足"。
