## 1. 概述

1.1 本政策适用于桌面应用「稿得快 GEO 客户端」（应用标识 `com.gaodekuai.geo`，产品名 `gdk-geo`，下称「本应用」）。本应用由陕西众友合联品牌运营管理有限公司（下称「我们」）开发并分发，是一款面向企业的生成式引擎优化（GEO）分析工具。

1.2 **本应用是本地优先的桌面软件**。它安装在您自己的电脑上，业务数据保存在您本机的数据库文件里。在当前 0.1 版本中：

- 我们**不运营**任何用于接收、汇聚或存储您业务数据的服务器；
- 本应用**不含**遥测、埋点、使用行为统计、崩溃自动上报或自动更新回连（详见第 3 节）；
- 本应用**没有**账号体系，不要求您注册、登录或向我们提供任何身份信息。

1.3 本应用会连接第三方服务（大语言模型 API、官方搜索 API、站长平台 API），但**只在您主动触发相应功能时**发生，且使用**您自己填入的 API Key** 或**您自己完成的 OAuth 授权**。这些请求由您的电脑直接发往相应第三方，我们不介入、不中转、不留存副本。

1.4 **您的角色**：您在使用本应用处理业务数据（品牌资料、官网内容、站长数据、生成内容等）时，您或您所属的企业是这些数据的个人信息处理者，须自行确保处理行为合法合规。我们仅在您主动提交缺陷报告、并自行选择附上日志片段时，接触您主动提供的信息。

1.5 **演示模式**：我们另提供一个纯前端的演示模式（在浏览器中打开，用于评估界面与流程）。演示模式使用预置静态数据、全部保存在浏览器内存中，**不连接任何后端、不调用任何第三方 API**；在演示模式里填入的 API Key 只留在浏览器内存，不写入系统钥匙串，页面刷新即消失。演示模式不是桌面应用的组成部分，正式发布的桌面应用不运行在演示模式下。

## 2. 涉及哪些信息

本应用不「收集」传统意义上的用户信息。以下三类信息会在您的设备上被处理，或在您主动发起的请求中经网络传输。

### 2.1 您主动填入的信息

| 信息 | 由哪个功能填入 | 保存位置 |
|---|---|---|
| 项目与品牌资料：项目名称、品牌名、别名、官网网址、地区、语言、行业、标签、归档状态 | 新建项目 / 项目设置 | 本地数据库 `projects` |
| 竞品清单：名称、别名、官网、备注、排序 | 项目详情 | `competitors` |
| 品牌实体卡：标准名、别名、成立年份、资质、产品与参数、价格区间、服务区域、案例、差异化卖点、官方口径、联系方式（电话 / 邮箱 / 地址）；以及逐字段的修订留痕 | 自动建档 / 手工编辑 | `entity_cards`、`entity_card_revisions` |
| 站点资产清单：URL、标题、类型、备注 | 自动建档 / 手工添加 | `project_assets` |

| 站长数据源绑定信息：数据源类型、站点 URL、GSC 的 OAuth Client ID（**非敏感**）、凭据状态、数据截至日、备注 | 站长数据 | `search_sources` |

| 文章生产：选题方向、提示词模板与槽位绑定、排期（频率 / 时间 / 星期）、生成的文章正文与状态 | 文章管理 | `article_directions`、`article_templates`、`article_schedules`、`articles` |
| 应用设置：界面语言、主题、字号、代理服务器地址、并发与频控参数、模型服务商与模型名与接口地址、采样温度与超时、通知偏好、上次导出目录、「数据外发」四项开关 | 设置 | `settings` 表 + WebView `localStorage`（见 §4.4） |
| 凭据：各家 API Key、OAuth token、OAuth client secret | 设置 → 模型服务商 / 密钥 | **只进系统钥匙串，不进数据库**（见 §4.2） |

🔴 **您填入什么，本应用就存什么。** 如果您在品牌资料、知识库、话术或文章里录入了自然人个人信息（例如联系人姓名、手机号、个人邮箱），这些信息会保存在您本机的数据库里，并可能随第 6 节所列路径发送给您自己配置的第三方 API。请勿录入与业务无关的个人信息。

### 2.2 应用在本机自动生成的信息

- **官网抓取结果**：您填入官网网址并触发「自动建档」后，本应用抓取该域名下同 host 的页面（单次上限 8 页、单页响应体上限 2 MB、单页超时 10 秒、整站超时按您设置的模型超时折算，默认 120 秒，并遵守该站点 `robots.txt`），解析出的正文用于生成品牌实体卡。抓取到的页面内容与解析结果保存在本地数据库。
- **AI 生成内容**：题库、关键词、FAQ、知识库条目、文章草稿、站点补丁草案。生成物一律以「待人工审核」状态入库。
- **采集记录**：每轮采集的问题文本、引擎与模型标识、通道类型、状态、失败原因、耗时、token 用量、AI 回答正文、回答中的引用链接与来源域名，以及元宝引擎的页面截图路径。
- **解析与核查结果**：提及判定、位次、情感倾向、事实核查问题清单与汇总、诊断快照、行动看板与行动事件。
- **报告与导出物**：您主动导出时生成的 Markdown / HTML / CSV / XLSX / PDF 文件，落在您在「另存为」对话框中选择的目录。
- **运行日志**：按日滚动的文本日志，文件名形如 `gdk-geo.log.YYYY-MM-DD`。日志中不包含 API Key（见 §7.2）。
- **浏览器会话数据**：元宝与百度站长两条通道会在本机建立独立的浏览器 profile 目录，其中包含**您自己登录**产生的会话数据（Cookie 等）。我们不读取、不解析、不上传这些内容（见 §4.3、§5.3）。

### 2.3 经第三方 API 传输的信息

当您触发相应功能时，以下内容会**直接从您的电脑**发送到您配置的第三方服务：

- **发给大语言模型**：提示词（含系统提示词）、您填入或抓取到的品牌资料正文、实体卡与知识库片段、待解析或待核查的 AI 回答文本、待生成的文章模板与槽位内容。
- **发给官方搜索接口**：搜索查询词（即题库里的问题文本）与返回条数上限。
- **发给站长平台 API**：站点 URL、数据区间；返回的是您自己站点的搜索指标。
- **发给您自己的站点**：标准 HTTP GET 请求，User-Agent 为 `geo-desktop/0.1 (+https://gaodekuai.local/bot)`。

完整清单见第 5 节。

## 3. 我们不收集什么

3.1 **无遥测、无埋点、无使用行为统计**：本应用不含任何遥测 SDK、埋点代码、广告 SDK 或第三方分析服务。我们不知道您打开了哪个页面、点击了哪个按钮、生成了多少篇文章、采集了多少轮。

3.2 **无崩溃上报**：本应用不含 Sentry、Crashlytics、Bugsnag 等任何崩溃或错误自动上报组件。程序出错时，错误信息只写入本机日志文件，不会自动发送给我们。

3.3 **无自动更新回连**：0.1 版本不含自动更新组件，本应用不会为检查更新而连接任何服务器。版本升级由您自行下载新版本安装包。

3.4 **不运营数据接收服务器**：我们没有用于接收您业务数据的后端服务，也没有任何「上报」通道。

3.5 **不收集账号信息与设备指纹**：本应用无注册登录，不采集设备标识符、MAC 地址、操作系统信息或安装列表用于用户画像。（提示：您向第三方 API 发起请求时，您的公网 IP 地址会被该第三方看到，这属于您与该第三方之间的直接通信。）

3.6 **不代管第三方平台账号凭据**：我们不收集、不存储、不传输您在腾讯元宝、百度站长等第三方平台的账号、密码、短信验证码或扫码登录凭据。相关登录一律由您在真实浏览器窗口中自行完成（见 §5.3）。

3.7 **不读取第三方平台的 Cookie 与私有接口**：百度站长通道只读取当前可见页面上的表格文本；脚本只读 DOM，不读取 Cookie 与 localStorage，不调用平台私有接口，不绕过验证码或登录风控，不代替您登录。

3.8 **前端不加载任何远程资源**：应用界面不从 CDN 加载脚本、样式或字体，不嵌入第三方网页组件、不加载第三方统计脚本。

3.9 **不实现「代客户登录第三方平台」**：本应用只通过 ①官方 OAuth / API ②您自己导出的文件 ③您自己复制粘贴的内容 ④您手工填报的数据 这四条途径获取第三方平台数据。

## 4. 数据存在哪里

### 4.1 本地 SQLite 数据库

单个文件 `geo.db`，以 WAL 模式打开，启动时自动执行数据库迁移。共 36 张业务表（项目、实体卡与修订、竞品、资产、题库、设置、关键词、FAQ、知识库与修订、站点档案与通道、补丁与事件、站长数据源与指标与机会、采集轮次 / 引擎执行 / 任务 / 记录 / 引用、回答洞察、事实核查、诊断快照、行动看板与事件、文章方向 / 模板 / 排期 / 文章）。

🔴 **该数据库文件在当前版本未做静态加密**（是标准 SQLite 文件）。任何能读取您用户目录的人或程序都能读取其中内容。请勿在共用电脑或未启用磁盘加密的电脑上处理敏感资料。

### 4.2 系统钥匙串（凭据）

凭据一律存放在操作系统的凭据存储中（macOS 登录钥匙串 / Windows 凭据管理器），service 名为 `com.gaodekuai.geo`。**数据库里只保存引用串**（形如 `keyring://llm/deep_seek`），**不保存凭据本身**。

| 钥匙串条目（account） | 内容 |
|---|---|
| `keyring://llm/deep_seek` | DeepSeek API Key |
| `keyring://llm/moonshot` | Kimi（月之暗面）API Key |
| `keyring://llm/volcengine_ark` | 火山方舟（豆包）API Key |
| `keyring://llm/ali_bailian` | 阿里云百炼（通义千问）API Key |
| `keyring://llm/baidu_qianfan` | 百度千帆（文心一言）API Key |
| `keyring://llm/tencent_hunyuan` | 腾讯混元 API Key |
| `keyring://llm/custom` | 自定义 OpenAI 兼容服务的 API Key |
| `keyring://llm/metaso` | 秘塔搜索 API Key |
| `keyring://llm/google_oauth` | Google OAuth 客户端密钥（可选；桌面客户端 + PKCE 可留空） |
| `keyring://llm/bing_wmt` | Bing Webmaster Tools 官方 API Key |
| `keyring://search/gsc` | Google Search Console 的 OAuth token（access / refresh / 过期时间） |

🔴 站点下发通道（WordPress / 边缘函数 / 代码仓库）在数据库中会写入一个形如 `keyring://site/<kind>/<project_id>` 的**引用串占位**，但 0.1 版本**没有任何流程会向该位置存入凭据值**，界面上的凭据状态也不会显示为「已保存」。也就是说：本应用当前**不托管**任何站点写回凭据。

### 4.3 本机文件

数据目录（`geo.db` 所在目录）：

- macOS：`~/Library/Application Support/com.gaodekuai.geo/`
- Windows：`%APPDATA%\com.gaodekuai.geo\`
- Linux：`~/.local/share/com.gaodekuai.geo/`

数据目录下的子目录：

- `screenshots/`：元宝引擎采集的页面截图，文件名形如 `yuanbao-<uuid>.png`；
- `browser-profile/yuanbao/`、`browser-profile/baidu_ziyuan/`、`browser-profile/baidu_ziyuan_ai/`：浏览器自动化通道的独立 profile。🔴 其中包含**您自己登录第三方平台**产生的会话数据（Cookie 等），由操作系统与浏览器管理，我们不读取、不解析、不上传；
- `logs/`：日志目录（应用内「设置 → 存储」显示的路径）。

日志实际写入操作系统为本应用分配的应用日志目录，文件名形如 `gdk-geo.log.YYYY-MM-DD`：

- macOS：`~/Library/Logs/com.gaodekuai.geo/`
- Windows：`%LOCALAPPDATA%\com.gaodekuai.geo\logs\`
- Linux：`~/.local/state/com.gaodekuai.geo/logs/`

导出文件：写在您通过「另存为」对话框选择的目录；该目录会被记住并显示在「设置 → 存储 → 导出目录」。

🔴 应用内「设置 → 存储」会显示数据目录、数据库文件、截图目录、日志目录与导出目录的路径。如与本节所列不一致，以您的操作系统与实际文件系统为准。

### 4.4 应用内 WebView 的本地存储

界面偏好保存在应用自带的 WebView `localStorage` 中，仅两个键，均在本机、不同步、不上传：

- `geo.preferences`：界面语言、主题、字号；
- `geo.wizard.draft`：新建项目向导中尚未提交的草稿。

## 7. 数据安全与密钥处理

7.1 **传输**：所有对外 HTTP 请求均使用 TLS（Rust `rustls` 实现，不依赖 OpenSSL）。

7.2 **密钥处理**：

- 密钥永不写入数据库、永不写入日志、永不出现在错误信息中；来自钥匙串的错误消息会经过一次兜底替换，密钥原文会被替换为 `***`；
- 界面只显示密钥「是否已保存」，**不回显**密钥内容；查询状态时只读取钥匙串条目的属性，不解密取值；
- 密钥仅在发起请求时从钥匙串读入进程内存并写入 HTTP 请求头；
- 钥匙串调用运行在独立线程上并设 10 秒超时，避免系统授权框无响应时拖住界面；
- 保存密钥时采用「先删后建」，以刷新 macOS 钥匙串条目的访问控制记录。

7.3 **本地数据库未加密**：见 §4.1。这是 0.1 版本的已知限制，加密存储（SQLCipher）在后续版本的计划中。

7.4 **没有全局「数据外发」开关**：0.1 预览版曾存在四个「预留开关」，因未与任何发送行为绑定、表述易生误导，已于 2026-11-13 版本**摘除**。实际会发生的数据外发以第 5、6 节所列路径为准，且除 §5.3 的站长数据周期取数外均由您主动操作触发。如需阻止数据离开本机，请不要触发第 6 节所列操作、不要填入相应 API Key、或不要完成相应 OAuth 授权。

7.5 **权限状态**：应用内「权限」三项（通知 / 文件与文件夹 / 屏幕录制）在当前版本尚未向系统申请，界面如实显示为「尚未询问」。

7.6 **第三方处理不受我们控制**：数据一旦发送到第三方 API，其后的处理（包括是否用于模型训练、留存多久）受该第三方的隐私政策与服务条款约束。各家大模型服务商的政策不同，请自行查阅并与之签订必要协议。

7.7 **您的设备安全**：本应用不提供设备锁定、多用户隔离或访问控制。数据库、截图、日志与浏览器 profile 都以您的操作系统用户权限存放，请自行启用磁盘加密与系统登录密码。

## 8. 数据留存与删除

8.1 **留存期限**：只要您不删除，数据就一直留在您的本机。我们不设定服务端留存期，因为我们没有服务端。

8.2 **在应用内删除**：项目支持归档与删除。删除项目会级联删除该项目下的竞品、站点资产、实体卡与修订、题库、关键词、FAQ、知识库条目与修订、站点档案与通道、补丁与事件、站长数据源与指标与机会、采集轮次 / 任务 / 记录 / 引用、回答洞察、事实核查、诊断快照、行动看板与事件、文章方向 / 模板 / 排期 / 文章等全部子数据（数据库外键 `ON DELETE CASCADE`）。应用设置不随项目删除。

8.3 **彻底删除（推荐做法）**：

1. 退出本应用；
2. 删除数据目录（§4.3 所列路径）——这会一并删除数据库、截图与浏览器 profile；
3. 删除日志目录；
4. 删除系统钥匙串中 service 为 `com.gaodekuai.geo` 的全部条目（macOS：打开「钥匙串访问」并搜索 `com.gaodekuai.geo`；Windows：打开「凭据管理器」）；
5. 删除您此前导出的报告、题库与交接单文件；
6. 应用内「设置 → 存储」可查看上述路径，也可直接点「打开目录」。

8.4 **卸载不等于删除**：卸载本应用**不会**自动删除数据目录、日志目录与钥匙串条目。请按 §8.3 手动清理。

8.5 **撤销第三方授权**：

- Google Search Console：请到 Google 账号的「安全性 → 您与第三方共享的内容」中撤销授权。仅在本应用里删除凭据**不会**撤销 Google 侧的授权；
- Bing Webmaster Tools：请在 Bing 后台吊销 API Key；
- 各家大模型与搜索 API Key：请到相应服务商控制台吊销；
- 腾讯元宝 / 百度站长：请在相应平台的账号设置中管理登录设备与会话；本应用侧可删除 `browser-profile/` 下对应的 profile 目录以清除本机会话。

8.6 **备份与导出物**：您导出的文件由您自行保管与删除，本应用不追踪它们的位置（仅记住最近一次导出目录）。
