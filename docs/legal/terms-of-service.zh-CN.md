5.1 **默认待审核**：本软件产生的全部内容（文章草稿、站点补丁草案、FAQ、知识库条目、关键词、诊断结论与报告文本等）在生成时一律标记为「待人工审核」（`pending_review`），需经您在本软件中显式「通过」后才进入可交付状态。

5.4 **AI 生成内容的标识义务**：依适用法律法规与发布平台规则，需要标识为人工智能生成内容的，由您自行完成标识。本软件在 0.1 版本**不自动添加**任何 AI 生成标识。

5.5 **导出物只收已审核内容**：本软件生成五种站点交付物（交接单 Markdown、`llms.txt`、`robots.txt`、`patches.json`、边缘函数骨架）。其中交接单、`llms.txt`、`robots.txt` 只纳入审核状态为「已通过」的补丁；`patches.json` 只纳入状态为「已发布」的补丁，而「已发布」在本软件中**必须先经人工审核通过**才允许设置。「待人工审核」与「已驳回」的内容不会进入任何交付物。请勿通过其他途径（例如直接复制未审核草稿）绕过这一约束。

5.6 **文章排期与自动生成**：桌面版本包含一个每 60 秒扫描一次的排期任务，到达设定时间后会自动调用模型生成文章。🔴 自动生成的文章同样一律进入「待人工审核」状态，**不会**自动对外发布；本软件不具备向您网站或任何第三方平台自动发布内容的能力。请据此合理评估自动生成产生的模型调用费用（该费用由您的 API Key 承担，见 §11.5）。

6.3 **我们不代登录**：🔴 本软件**不实现、也不允许被用于**「代客户登录第三方平台」。对于没有官方读取接口的平台（例如腾讯元宝网页版、百度搜索资源平台），本软件的做法是：在您本机上打开一个**可见的**浏览器窗口，**由您自己扫码或输入账号登录**；本软件不注入账号密码、不读取 Cookie 与 localStorage、不调用平台私有接口、不绕过验证码或登录风控。

6.4 **本机会话数据由您负责**：上述浏览器通道会在您本机建立独立的浏览器 profile 目录，其中包含您自己登录产生的会话数据。这些目录不由我们读取或上传，但**任何能访问您电脑用户目录的人或程序都可能读取它们**。请勿在共用设备上使用这些通道；不再需要时可删除对应 profile 目录。

7.3 **本软件不托管站点凭据**：数据库中会为站点通道写入一个引用串占位，但当前版本没有任何流程会向该位置存入密码或 token，界面上的凭据状态也不会显示为「已保存」。
