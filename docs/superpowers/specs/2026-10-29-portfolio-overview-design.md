# M9 组合总览（多项目）设计与 demo 落地

> 状态：demo 侧已落地（2026-10-29）
> 路由：`/portfolio`（左侧栏「项目」下的「组合总览」）
> 关联：`2026-10-29-project-overview-home-design.md`（项目级概览）、差异台账 E-73

## 1. 定位

单项目概览回答"这个客户现在怎么样"；组合总览回答"**哪些客户有结论、哪些还没采集、哪些最需要处理**"。
它是服务商/多项目客户的入口，不做单项目的深挖。

## 2. 信息架构

```
标题 / 副标题 / 刷新
演示口径常驻（未采集≠0 分；比率只给分布，不平均）
五张计数卡：项目数 / 有结论 / 样本不足 / 未读告警 / 总样本量
指标分布卡：min — 中位数 — max + 范围条；可切换 覆盖 / 总分 / SOV
筛选 + 搜索 + 排序
项目清单表：项目 / 最近结论 / 覆盖 / 总分 / SOV / 未读告警 / 操作
```

## 3. 交互（复合但克制）

| 交互 | 行为 |
|---|---|
| 计数卡 | 账户级汇总，**不随筛选变化**（筛选只影响表格） |
| 分布卡 | `Segmented` 切换三个指标；范围条显示 min–max，中点标中位数 |
| 筛选 | 全部 / 有结论 / 待采集 / 有告警；每个标签带计数 |
| 搜索 | 项目名或品牌名子串，输入即筛（大小写不敏感） |
| 排序 | 先看风险（默认）/ 覆盖从低到高 / 最近采集；无结论行永远排最后 |
| 行点击 | 进入该项目的概览 |
| 行内按钮 | 有结论 → 打开概览；待采集 → 去采集页；读取失败 → 打开概览看错误 |
| 分布切换 | 只切视图，不改筛选与排序 |

## 4. 口径（硬约束）

1. **比率不平均、不求和**：不同项目的分母（题量 / 引擎覆盖 / 同框题数）不同；
   组合层只给 **min / 中位数 / max 分布**与逐项目行。
2. **未采集 ≠ 0 分**：待采集行不参与任何指标分布，排序时排最后。
3. **归档项目默认排除**；本轮没有"包含归档"开关。
4. **不做跨项目环比**：不同项目的轮次时间不同，相减没有意义。
5. **组合层风险本轮只取未读告警**，列名写"未读告警"；完整风险队列在项目概览。
6. `total_sample_size` 可以求和（计数，不是比率）。

## 5. 取数与后端

- 本轮**命令面零新增**（`IPC_COMMANDS` 仍 105）：
  - `project_list`（include_archived=false）
  - 每个项目：`collection_board` → `diagnosis_overview`（最近有结论轮次）
  - 前端 `buildProjectSnapshot` → `summarizePortfolio` → `filterPortfolioRows`
- 取数是 **N+1**（每项目 2 次读）；demo 只有 3 个活跃项目，可接受。
- 🔴 M9 真后端应提供 `portfolio_overview`（一次往返返回每项目快照），否则项目数一多就会放大成
  N 次 IPC。页面只替换取数段，统计与筛选口径不变（E-73）。
- 单项目读取失败：行内标"读取失败"并带错误码 Tooltip；顶部给"N 个项目读取失败"提示；
  不整页红屏（规则 8）。

## 6. 演示数据

为了让组合页不是"只有一行"，`SEED_PROJECTS` 增加两个 **active 但尚未采集** 的项目：
`澄川水处理设备`、`禾野食品供应链`。它们没有轮次 / 诊断 / 处方，用来走查：
- 待采集行的空态与"去采集"；
- 分布只统计 1 个有结论的项目；
- 筛选"待采集 2"；
- 归档项目（云栖）默认不出现。

- 组合层的完整风险队列（事实核查 / 复核）与处方进度列：先保持"未读告警"这一列。
- 组合页导出 CSV / 报告：先给单项目报告。
